# Калорийка — дневник КБЖУ в Telegram

Mini App для Telegram: считает калории, белки, жиры и углеводы за день, сканирует штрихкоды продуктов в магазине.

## Что умеет

- Дневник по приёмам пищи (завтрак, обед, ужин, перекус) и по дням, график за 7 дней.
- Сканер штрихкодов камерой: EAN-13, EAN-8, UPC, а также DataMatrix «Честного знака» и QR формата GS1 — из них достаётся код товара.
- Если камеру не дали — можно сфоткать штрихкод или ввести цифры руками.
- Поиск по встроенной базе (~110 базовых продуктов) и по базе Open Food Facts.
- Если продукта нет в базе — вписываешь КБЖУ с упаковки один раз, дальше он находится по скану сразу.
- Расчёт нормы по формуле Миффлина — Сан-Жеора (пол, возраст, рост, вес, активность, цель) или свои цифры.
- Данные хранятся в Telegram CloudStorage — синхронизируются между устройствами пользователя, сервер не нужен.
- Подстраивается под светлую и тёмную тему Telegram.

## Как устроено

Чистый HTML/CSS/JS без сборки, хостинг на GitHub Pages.

- `index.html`, `styles.css`, `app.js` — само приложение
- `foods.js` — встроенная база базовых продуктов (средние значения на 100 г)
- `vendor/` — распознавание штрихкодов ([barcode-detector](https://github.com/Sec-ant/barcode-detector) на основе zxing-cpp, MIT)

Данные о продуктах по штрихкоду: [Open Food Facts](https://world.openfoodfacts.org), лицензия ODbL.

## Подключение к боту

1. В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя и юзернейм.
2. `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → вставить ссылку на приложение и название кнопки.
3. По желанию: там же **Configure Mini App** → включить, чтобы в профиле бота была кнопка «Открыть».

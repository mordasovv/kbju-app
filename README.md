# Калорийка — дневник КБЖУ в Telegram

Mini App для Telegram: считает калории, белки, жиры и углеводы за день, сканирует штрихкоды продуктов в магазине.

## Что умеет

- Дневник по приёмам пищи: стандартные четыре плюс свои (переименовать, добавить, удалить).
- Сканер штрихкодов камерой: EAN-13, EAN-8, UPC, DataMatrix «Честного знака», QR формата GS1. Запасные пути — фото штрихкода и ввод цифр.
- Поиск по встроенной базе (~320 базовых продуктов, понимает «яйца», «хурму», «молоко 3,2») и автоматически по Open Food Facts — сначала товары России.
- Штрихкода нет в базе — находишь продукт по названию, приложение запоминает штрихкод. Весовые этикетки магазина запоминаются так же, вес с этикетки подставляется подсказкой.
- `SHARED_CODES` в `foods.js` — общая база штрихкодов для продуктов, которых нет в открытой базе.
- Запись блюда целиком: только ккал и БЖУ.
- Свои блюда: ингредиенты с граммами, вес готового блюда, порции — КБЖУ считаются сами.
- «Как вчера»: повтор приёма пищи или всего дня одной кнопкой.
- Вода: стаканы, литры или миллилитры, свой объём стакана и норма.
- Вес: дневник с графиком и изменением за 30 дней.
- Статистика за 7 и 30 дней: среднее, дни в норме, БЖУ, серия дней с записями, вода.
- Своя норма калорий и БЖУ или расчёт по формуле Миффлина — Сан-Жеора.
- Чёрно-белое оформление под светлую и тёмную тему Telegram, цвет только у БЖУ, воды и статусов.
- Данные в Telegram CloudStorage — синхронизируются между устройствами, сервер не нужен.

## Как устроено

Чистый HTML/CSS/JS без сборки, хостинг на GitHub Pages.

- `index.html`, `styles.css`, `app.js` — само приложение
- `foods.js` — встроенная база продуктов (средние значения на 100 г) и общая база штрихкодов
- `vendor/` — распознавание штрихкодов ([barcode-detector](https://github.com/Sec-ant/barcode-detector) на основе zxing-cpp, MIT)

Данные о продуктах по штрихкоду: [Open Food Facts](https://world.openfoodfacts.org), лицензия ODbL.

## Подключение к боту

1. В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя и юзернейм.
2. `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → вставить ссылку на приложение и название кнопки.
3. По желанию: там же **Configure Mini App** → включить, чтобы в профиле бота была кнопка «Открыть».
